## Definitions

All three features are evaluated at the ego rear-axle position of the start lidar frame.

| Column | Definition |
|---|---|
| `lane_type` | `lane` if a lane polygon covers ego (a lane wins over a connector), else `lane_connector` if a connector polygon does, else `none` |
| `in_intersection` | ego covered by an intersection polygon (boundary counts as inside) |
| `traffic_light_state` | most restrictive red > yellow > green status at the start frame among the relevant connectors (ego connectors, else connectors leaving the ego lane via `exit_lane_fid`); `unknown` if none has a record, `none` if there are no relevant connectors |

Each feature has a `*_missing` flag, True where the value is null (no ego point, map or status data). Map ids are kept in `scenario_map_alignment.parquet` and never in the model tables.

Map layers are stored in WGS84 lon/lat and are reprojected per city to the map's `projectedCoordSystem` (UTM) before the lookup.
