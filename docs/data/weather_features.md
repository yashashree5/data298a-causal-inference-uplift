# Weather features

Generated by `python -m tools.extract_weather_features check` (weather-v1, 2026-10-29T20:00:33+00:00).
Source: [Open-Meteo Historical Weather API](https://open-meteo.com/en/docs/historical-weather-api), model `ecmwf_ifs` (~9 km), licence CC BY 4.0.
Tables stay outside Git in `D:\nuplan\processed\weather\`; this report and the code are committed.

## Time alignment

Each scenario uses the UTC hour **at or before** its simulation start (anchor - 3 s). Instant values (temperature, humidity, cloud cover, wind speed, weather code) are taken at that hour; precipitation, rain and gusts are Open-Meteo totals/maxima over the preceding hour, and the 3-hour precipitation sums the three hours ending there. Sun elevation is computed at the exact start time. No value describes time after simulation start.

## Features

| Column | Meaning |
|---|---|
| `weather_temperature_c` | Air temperature at 2 m |
| `weather_relative_humidity_pct` | Relative humidity at 2 m |
| `weather_cloud_cover_pct` | Total cloud cover |
| `weather_wind_speed_kmh` | Wind speed at 10 m |
| `weather_code` | WMO weather code (categorical) |
| `weather_precipitation_mm` | Precipitation in the hour before start |
| `weather_rain_mm` | Rain in the hour before start |
| `weather_precipitation_prev_3h_mm` | Precipitation in the 3 hours before start (wet road proxy) |
| `weather_wind_gusts_kmh` | Maximum gust in the hour before start |
| `sun_elevation_deg` | Solar elevation at start; below 0 is night, 0 to -6 civil twilight |

## Limits

- These are model estimates for a ~9 km grid cell, not measurements at the vehicle. Visibility is not provided by the historical API and is not included.
- Every benchmark candidate was recorded in daylight (about 07:00-17:00 local time), so there are no night scenarios and sun elevation varies only between morning, midday and afternoon.
- Las Vegas has no wet hours at all in its recording period; rain information comes from the other three cities.
- Weather does not alter the nuPlan simulation; it can only explain planner differences through the recorded traffic situations it co-occurs with.
- Variation is limited and tied to city and drive: scenarios from one drive share an hour, and each city was recorded over a few weeks of one season. Report weather effects per city and treat them as weak evidence.
- A different archive model (for example ERA5) gives noticeably different hourly precipitation; the model is pinned and recorded so results are reproducible.

- PASS: scenario_id unique in each table
- PASS: no missing weather values
- PASS: weather hour is at or before simulation start (lag 0 to <1 h)
- PASS: values within physical ranges
- PASS: rain never exceeds precipitation
- PASS: 3-hour precipitation >= current hour
- PASS: model grid point within 10 km of every city point
